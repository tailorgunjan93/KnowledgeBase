## Phase 2: Backend Implementation

### 2.1 Supervisor-Worker Pattern
- **Supervisor**: Orchestrates tasks, manages worker pool
- **Workers**: 
  - EmbeddingWorker: Generate embeddings
  - RetrievalWorker: FAISS/BM25 search
  - GenerationWorker: LLM response generation
  - ValidationWorker: Fact-checking

### 2.2 Retrieval System
- **FAISS**: Dense vector similarity search
- **BM25**: Sparse keyword-based retrieval  
- **Hybrid**: Combine both with reciprocal rank fusion
- **Embeddings**: sentence-transformers (all-MiniLM-L6-v2)

### 2.3 Anti-Hallucination
- Source attribution with confidence scores
- Self-consistency checking
- Fact verification against retrieved docs
- Confidence scoring (0-1)
- Self-correction loop with retry logic
